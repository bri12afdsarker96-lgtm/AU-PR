## 4. 项目是什么 · 颗粒度纪律（口径基准浓缩）

**AU&PR = 水星配音对齐工作室（Mercury Dub Align Studio）**，音频驱动的分镜对齐软件，**非商用**。
完整口径见 `docs/配音对齐工作室架构与路线_20260722.md`（有出入以那份为准）。

核心链路（设计锁定版）：

> 整篇文案 → fish-speech / dots.tts **整篇克隆**出连贯 master.wav（音色不漂移）
> → whisper **逐行量真实时长**（只当尺子、不切音频、无静音吸附，每句 ≥5s）
> → 每句画面按该时长**裁剪/变速**对齐 → **一句一画面**顺序拼接
> → **整条 master 叠为唯一音轨** → 末段吸收帧舍入残差，**帧级收口**。

**三种粒度，三条纪律**（对齐的"颗粒度"就是指这个）：

```
篇级   整篇文案 / 整条 master.wav / 整条成片   —— 音频只在此粒度存在，任何模块不得切 master
行级   一行脚本 = 一句配音时长 dur_i = 一个画面（≥5s，变长；唯一对齐单位）
帧级   30fps 帧栅格 = 渲染最小单位          —— 只在渲染层出现，上游只传秒
```

五层架构：L1 文案 → L2 配音（封闭双引擎 dots_local/fish_local + mock）→ L3 计时（whisper 尺子）
→ L4 编排（复用水星内核五档裁剪/变速）→ L5 渲染（帧收口 + 整轨叠加）。

## 8. 常见坑（换机后最容易踩）

1. **只看 main → 以为项目只有文档**。→ 认准 `release/v0.5-download-fix`（§1）。
2. **模型/音色"丢失"**：数据总目录没指对，或曾设在 `dist\` 内被打包清掉。
   → 指向 `D:\GitHub\By\AU&PR\水星配音数据`；软件已支持向上两级回退自动找回。
3. **ffmpeg 放了却找不到**：把 `ffmpeg.exe`/`ffprobe.exe` 放 exe 同目录、数据总目录或 PATH；
   `settings.ffmpeg_tool()` 会主动搜已知目录返回绝对路径。
4. **弹窗"无法定位程序输入点 aoti_torch_…"**：torch 生态包 DLL 与 torch 小版本 ABI 锁死。
   → `python -m pip uninstall -y torchcodec`（本软件不需要它）。
5. **打包"拒绝访问 WinError 5"**：dist 被占用。→ 关软件窗口（含最小化黑框）/ 关资源管理器 / 暂停杀毒；
   `项目打包.bat` 已自动 taskkill 旧进程 + 预清理检查。
6. **dots.tts 长参考劣化**：参考音频 5–30s；超 30s 触发 `max_generate_length` 断言（§5）。
7. **轻量 exe 跑不了 dots.tts**（看不到系统 Python 包）→ 源码运行或用整合离线版。
