# 配音对齐工作室（Dub Align Studio）架构与路线

生成日期：2026-07-22
状态：口径基准（后续开发以本文为准；颗粒度与契约变更需先改本文）
定位：**独立新软件**，复用水星剪辑（integrated_workbench）对齐内核；**非商用**。

## 一、产品构思（锁定版）

整合 Fish Audio S2 Pro / dots.tts（整篇声音克隆）与水星剪辑「配音对齐分镜」（画面对齐），
解决逐句独立配音的**音色/韵律漂移**问题：

> 整篇文案 → 引擎整篇克隆出**连贯 master.wav**（音色不漂移）
> → whisper **逐行量出各自真实时长** dur_i（变长，业务下限 ≥5s；只当尺子，不切音频，不做静音吸附）
> → 每句画面按 dur_i 裁剪/变速填满（复用五档策略）→ **一句一画面**顺序拼接
> → **整条 master 叠为唯一音轨**（B 方案：整轨叠加，零拼接、零漂移）
> → 末段吸收帧舍入残差，收口保证「画面总长 = master 总长」。

关键取舍：

- 音频从头到尾整条叠、**永不切割**；行边界只是「这句多长」的时长数字，不是切点，
  视觉切点落在句中亦无碍 → **不需要静音吸附**；
- 每句脚本 ≥5 秒（业务约束）→ 不存在画面一闪而过，whisper 相对误差被摊薄，行级粒度天然容错；
- 唯一必做的工程硬点：**帧收口**（Σ帧数 == round(master×fps)，末段吸收残差）。

## 二、颗粒度模型（全系统三种粒度，三条纪律）

```
篇级   整篇文案 / 整条 master.wav / 整条成片（音频只在此粒度存在）
行级   一行脚本 = 一句配音时长 dur_i = 一个画面（≥5s，变长；唯一对齐单位）
帧级   30fps 帧栅格 = 渲染最小单位（只在渲染层出现）
```

纪律：

1. 音频永远是篇级——任何模块不得切 master；
2. 对齐、语义、UI 交互永远是行级——不做词级/字级功能（whisper 字级时间戳仅内部计算）；
3. 帧级只属于渲染层——上游传秒（浮点），渲染层负责量化与收口。

## 三、五层架构

```
L1 文案层     整篇文案 → 脚本行列表（复用 semantic_match.parse_script）
L2 配音层     DubEngine.synthesize_full(text, voice) → master.wav + 元数据 【封闭双引擎】
L3 计时层     Aligner.measure(master, lines) → [LineTiming]；产物：配音计时表.csv
L4 编排层     行级(text, dur_i, video_i) → 五档裁/变速 + 语义匹配（复用内核，零改动）
L5 渲染层     quantize_to_frames → 逐行无声段 → concat → 叠整轨 master → 收口断言
```

层间只靠文件契约与已冻结接口耦合；L2 与 L3 相互独立，可并行开发。

### L2 引擎清单（封闭，不留其他接口扩展位）

| 引擎 | 形态 | 要点 |
|---|---|---|
| `dots_local` | pip 包，进程内 Python API | dots.tts 2B，48kHz，Apache-2.0（代码+权重），显存 5.6–10.5GB，消费级卡可跑；克隆：参考音频（+可选转写文本，相似度最高） |
| `fish_local` | 本地 HTTP 服务 | fish-speech S2 Pro 4B，80+ 语种，Fish Audio Research License（非商用无碍）；克隆：参考音频 10–30s |
| `mock` | 纯 Python 确定性假引擎 | 单测/验收专用（TTS 非确定，确定性断言只对 mock 做） |

适配器设计定案：

- 形态差异被接口吃掉：dots 进程内直调、fish 走本地服务，上层只见 `synthesize_full`；
- 采样率写进契约：dots 48kHz、fish 通常 44.1kHz，元数据如实记录，渲染层叠轨统一转 AAC；
- 音色库统一：一个音色 = 参考音频（+可选转写文本），两引擎共用，`voice_id` 落计时表；
- 模型权重走**组件下载 + SHA256 校验**，不进安装包（沿用水星轻量安装纪律）。

## 四、数据契约

- **master 元数据**（master.json，随 master.wav 落盘）：
  `engine / voice_id / model / seed / sample_rate / seconds`
- **配音计时表.csv**（L3 产物，UTF-8-SIG）：
  `index, text, start, end, duration`；约束 Σduration == master 总长（对时间轴完整划分）
- **音色库**：`音色库/<voice_id>/参考音频.wav + 转写.txt(可选) + 音色.json`

## 五、复用边界（水星剪辑对齐内核，零改动）

- `edit_compose.match_video_to_audio`：五档裁剪/变速（画面对齐到配音时长）
- `semantic_match`：parse_script 及情绪→特效/转场/音效（M4 可选增强）
- `proc.run_silent`：静默子进程（ffmpeg/whisper 不弹黑框）
- whisper-cli / ggml 模型：复用现有 `model_registry` + `component_download` 组件模式

## 六、里程碑

```
M1.5 ✅ ──┬─ M2a dots.tts ─→ M2b fish-speech ─┐
          └─ M3 whisper 尺子 ────────────────┴─→ M4 产品化
```

- **M1.5（已完成）**：B 渲染几何验证——MockAligner + 帧收口 + 整轨叠加端到端跑绿；
  冻结 `Aligner`/`LineTiming` 接口与收口断言。后续阶段只替换假件，不动骨架。
- **M2a dots.tts 先行**：`DubEngine` 接口 + dots 进程内适配 + mock 引擎 + 音色库雏形。
  验收线：N 行文案 → 单条 master.wav + 元数据落盘；无 GPU/未装包时明确降级提示，不静默卡死。
- **M2b fish-speech**：本地 server 适配（启动/健康检查/超时），复用 M2a 接口与音色库。
- **M3 whisper 尺子**：`WhisperAligner`（字级时间戳→按脚本行汇总为行级时长）+ 计时表落盘 +
  自洽校验（Σdur≈总长、≥5s 下限告警）；`SilenceAligner` 轻量回退。
  验收线：真语音 + 已知脚本 → 逐行时长相对误差 <5%；计时表直接喂 M1.5 渲染出片。
- **M4 产品化**：应用外壳（文案上传/音色选择/一键成片）、行级计时手动微调、
  语义编排接入、成片对接矩阵产线、workflow/capability 验收项、契约文档两侧登记。

## 七、验收纪律（与水星验收体系同构）

- 一切**确定性断言**（帧收口、契约格式、五档分支）进单元测试（走 mock）；
- 一切**非确定组件**（fish、dots、whisper、GPU）只进 capability-check 探测项；
- 每阶段收口：`compileall` 全绿 + 新旧单测全绿 + 端到端 `verify` 跑绿。
