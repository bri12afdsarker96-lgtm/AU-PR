# AU&PR 路线图

## P0：研究仓库定盘

- 完成项目定位、架构、调研笔记。
- 明确不把第三方权重、私有源码、token 和大媒体产物提交进仓库。
- 确定远端仓库名、可见性和许可证策略。

## P1：核心数据链路

- 建立项目目录结构。
- 实现脚本拆句与 `script_lines.jsonl`。
- 实现 `audio_manifest`、`shot_manifest`、`alignment_plan` 三类 schema。
- 提供 mock TTS，先不依赖真实 Fish S2 Pro。

## P2：Fish S2 Pro 适配

- 接入本地 Fish Speech 服务模式。
- 增加命令行推理兜底。
- 支持逐句生成、批量生成、单句重生。
- 记录音色、情绪标签、生成参数、音频 hash 和时长。

## P3：分镜对齐 MVP

- 用 FFprobe 读取音频和视频时长。
- 实现自然排序配对。
- 实现保持原速、裁剪、慢放、末帧定格。
- 输出 `alignment_plan.json/csv`。
- 用 FFmpeg 合成成片。

## P4：复核台

- 可视化每句台词、音频、分镜和对齐策略。
- 支持替换单句音频、替换单个镜头、修改裁剪锚点。
- 支持单句重生配音后局部重算。
- 标记缺失、失败和时长异常。

## P5：生产导出

- 输出 MP4、音画对齐表、渲染清单。
- 导出剪映草稿包。
- 预留 Premiere XML/EDL 导出。
- 支持 9:16、16:9、1:1、4:3、3:4。
