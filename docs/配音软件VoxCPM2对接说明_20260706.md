# 配音软件（VoxCPM2）对接说明

生成日期：2026-07-06

## 边界

配音由**外部软件**完成，主模型 `openbmb/VoxCPM2`：它按上传文本**逐行生成音频文件**（一行=一句=一个音频）。本软件**不做 TTS**，只负责消费其产物、与多个分镜片段对齐并音画同步。

## 数据流

```
① 上传文本（一行一句）
   └─ dub_bridge.write_dub_script → 配音脚本.csv（index, text, audio_file, duration_seconds）
② 交给 VoxCPM2 软件 → 逐句生成音频，回填 audio_file / duration
③ 本软件摄入配音包目录（dub_sync 认「配音清单.csv」或按自然序读 WAV）
④ dub_bridge.build_aligned_plan：文本行 ↔ 逐句音频 ↔ 分镜片段 按序对齐，
   每句挂语义匹配（情绪→特效/转场/音效）+ 音画同步（按配音时长裁剪/变速）
⑤ 渲染：逐句画面对齐到配音时长，合成多分镜成片
```

## 对接契约（配音包目录）

VoxCPM2 软件产出目录建议包含：

- 逐句音频文件：`001.wav`、`002.wav` …（与文本行一一对应，序号即行号）
- 配音清单：`配音清单.csv`，列可用中英别名：
  - `index / 序号` — 行号（与文本、分镜对齐用）
  - `text / 文案 / 台词` — 该句文本
  - `audio_file / 音频文件` — 音频文件名
  - `duration_seconds / 时长` — 音频时长（秒，可选；缺省时本软件实测）

无清单时，本软件按文件名自然序（001、002…）配对，仍可工作。

## 关键点：逐句音画同步

每句配音单独一个音频 → 与对应分镜片段按 `edit_compose.match_video_to_audio` 同步：

- **裁剪多余画面**：分镜比配音长→裁到配音时长；短→放慢补足；
- **变速匹配**：调分镜速度等于配音时长；音频保持自然速度→**逐句音画同步**。

成片总时长 = 各句配音时长之和（画面对齐到配音）。
