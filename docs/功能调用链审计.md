# 功能调用链审计

> v0.7.71 P1 · 目标：每一个用户可见的功能都能追到"最终消费位置（引擎调用 / ffmpeg 参数 / 产物字段）"，不允许"UI 里能操作但从不进入执行链"的假功能。
>
> 每行记录：UI 控件 → payload 字段 → 后端解析 → **最终消费** → 支持范围 → 自动化测试 → 是否仍需真人验收。

## 图例
- ✅ = 有自动化测试覆盖
- 🧪 = 网络/ffmpeg mock 覆盖，真产物需真人验收
- ⏳ = 待真人真机验收
- ⚠ = 已知功能限制或产品选择
